# Code of Conduct

TopoExec contributors are expected to keep discussion technical, respectful, and
focused on making the runtime safer and easier to review.

## Expected behavior

- Be kind and direct.
- Critique ideas, evidence, and tradeoffs rather than people.
- Assume good intent, but correct unsafe claims quickly.
- Keep scope, validation, and compatibility concerns visible.
- Credit prior work and explain rejected alternatives.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information or credentials.
- Dismissing safety, security, or compatibility concerns without evidence.
- Misrepresenting preview/deferred features as production-ready.

## Enforcement

Maintainers may edit, hide, close, or lock issues/PRs that violate this code of
conduct. Serious or repeated violations may result in blocked participation.
When a private report channel is available for the repository, use it for
sensitive conduct reports; otherwise contact the repository owner through GitHub.
